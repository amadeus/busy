Busy is installed

Open Busy from Applications, or run busy in Terminal.

Try busy --duration 2h for a timed session, busy status to check it, and busy stop to quit.

The default battery cutoff is 20%. Change it with busy --battery-cutoff 25 or from the menu bar.

If your shell cannot find the command, add /usr/local/bin to your PATH or run /usr/local/bin/busy.
